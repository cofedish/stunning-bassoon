# 10. Алгоритмы на графах

Граф — пара `G = (V, E)`, где `V` — вершины, `E` — рёбра. Универсальная модель: соцсети, дороги, зависимости задач, состояние игры.

## Терминология

| Термин | Что |
|---|---|
| Ориентированный (digraph) | Рёбра имеют направление |
| Неориентированный | Рёбра двунаправленные |
| Взвешенный | У каждого ребра есть вес (стоимость, длина) |
| Степень вершины | Сколько рёбер инцидентно |
| Путь | Последовательность вершин, соединённых рёбрами |
| Цикл | Путь, начинающийся и кончающийся в одной вершине |
| DAG | Directed Acyclic Graph — ориентированный без циклов |
| Связный | Между любой парой вершин есть путь |
| Дерево | Связный неориентированный граф без циклов, V вершин ↔ V-1 рёбер |

## Способы хранить граф

| Способ | Память | Проверка `(u, v) ∈ E` | Перебор соседей |
|---|---|---|---|
| Матрица смежности `n×n` | O(V²) | O(1) | O(V) |
| Список смежности | O(V + E) | O(deg) | O(deg) |
| Список рёбер | O(E) | O(E) | O(E) |

В разреженных графах (E << V²) — список смежности. В плотных — матрица.

## Топологическая сортировка (DAG)

Линейный порядок вершин: для любого ребра `u → v` вершина `u` стоит раньше `v`. Применение: порядок выполнения задач, компиляция модулей.

**Алгоритм Кана** (на in-degree):
1. Вычислить `in_degree[v]` для всех вершин.
2. Положить в очередь все вершины с `in_degree == 0`.
3. Доставать вершину, добавлять в результат, уменьшать `in_degree` соседей. Если у соседа стало 0 — в очередь.
4. Если результат содержит все V — порядок построен. Иначе в графе есть цикл.

O(V + E).

## Кратчайшие пути

### Дейкстра — от одной вершины ко всем (только неотрицательные веса)

```
dist[s] = 0; dist[v] = +∞ для остальных
PQ = min-heap, кладём (0, s)
while PQ:
    (d, u) = pop_min(PQ)
    if d > dist[u]: continue           # устаревший элемент
    for (v, w) in adj[u]:
        if dist[u] + w < dist[v]:
            dist[v] = dist[u] + w
            push(PQ, (dist[v], v))
```

O((V + E) log V) с бинарной кучей.

**Внимание**: при отрицательных весах Дейкстра может выдать неверный ответ.

### Беллман-Форд — отрицательные веса OK, но без отрицательных циклов

Релаксируем все рёбра V-1 раз. Если на V-й итерации ещё есть улучшения — есть отрицательный цикл. O(V × E).

### Флойд-Уоршелл — все пары вершин

```
for k in V:
    for i in V:
        for j in V:
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

O(V³). Хорош для маленьких плотных графов.

### A* — Дейкстра + эвристика
Нужна допустимая (не переоценивающая) эвристика `h(v)`. Для сетки — манхэттенское/евклидово расстояние.

## Минимальное остовное дерево (MST)

Нашли подмножество рёбер, соединяющее все вершины с минимальной суммой весов.

### Kruskal (сортировка + DSU)
Сортируем рёбра по весу, добавляем по очереди если концы в разных компонентах. O(E log E).

### Prim (растим дерево)
Начинаем с одной вершины. На каждом шаге через min-heap берём минимальное ребро на границе. O(E log V).

## DSU / Union-Find

Структура для работы с непересекающимися множествами. Две операции:
- `find(x)` — представитель множества элемента x.
- `union(x, y)` — объединить множества.

С эвристиками **по рангу + сжатие пути** — практически O(1) на операцию (точнее, O(α(n))).

Применение: Kruskal, проверка связности онлайн, оффлайн-обработка запросов.

## Поиск циклов

- **Неориентированный**: DFS, помечаем посещённые. Если соседа уже видели и он не родитель — цикл.
- **Ориентированный**: DFS с тремя цветами:
  - белый (не посещён),
  - серый (в текущей ветке рекурсии),
  - чёрный (вышли).
  Если из серой попали в серую — цикл.

## Сильно связные компоненты (SCC)

Подмножество вершин, где из каждой достижима каждая. Алгоритмы: **Тарьян** или **Косараджу** (DFS + транспонирование графа).

## Шпаргалка «что брать»

| Задача | Алгоритм |
|---|---|
| Кратчайший путь, веса = 1 | BFS |
| Кратчайший путь, веса >= 0 | Дейкстра |
| Кратчайший путь с отриц. весами | Беллман-Форд |
| Все пары | Флойд-Уоршелл |
| Минимальное остовное дерево | Kruskal или Prim |
| Цикл в неор. графе | DFS |
| Цикл / порядок в DAG | Топосорт (Кан) |
| Связность онлайн | DSU |
| Кратчайший путь с эвристикой | A* |
