# Шпаргалки к финалу

Сборник кратких конспектов по 10 темам подготовки. Каждая папка — отдельный пункт плана, внутри `README.md` с теорией и файлы с примерами кода (Python / Go где применимо).

## Содержание

| # | Тема | Папка |
|---|------|-------|
| 01 | Алгоритмы обхода и поиска (BFS, DFS) | [01-search-algorithms](./01-search-algorithms) |
| 02 | Системы контроля версий — основы Git | [02-git-basics](./02-git-basics) |
| 03 | Git: ветки, merge, rebase | [03-git-branches](./03-git-branches) |
| 04 | Работа с JSON | [04-json](./04-json) |
| 05 | Внешние API у БЯМ (LLM, GigaChat) | [05-llm-api](./05-llm-api) |
| 06 | Структура HTTP-запросов | [06-http](./06-http) |
| 07 | Динамическое программирование | [07-dynamic-programming](./07-dynamic-programming) |
| 08 | Жадные алгоритмы | [08-greedy](./08-greedy) |
| 09 | Команды для работы с удалёнными репозиториями | [09-git-repos](./09-git-repos) |
| 10 | Алгоритмы на графах | [10-graphs](./10-graphs) |

## Как пользоваться

1. Идёшь по пунктам плана сверху вниз — по 1 в день.
2. В каждой папке: сначала `README.md` (теория + сложности + ловушки), затем `examples.py` / `examples.go` (рабочий код, можно запускать).
3. Все примеры самодостаточны — копируй и запускай.

## Запуск примеров

```bash
# Python
python 01-search-algorithms/examples.py

# Go
go run 01-search-algorithms/examples.go
```

Требования: Python 3.10+, Go 1.21+.
