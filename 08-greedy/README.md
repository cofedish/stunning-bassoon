# 08. Жадные алгоритмы

Идея: на каждом шаге берём **локально оптимальный** выбор и надеемся, что это приведёт к **глобальному оптимуму**.

## Когда работает

Жадность даёт правильный ответ, если у задачи есть:
1. **Оптимальная подструктура** — оптимум целого собирается из оптимумов частей.
2. **Свойство жадного выбора** — есть локальный критерий, для которого можно доказать: всегда существует оптимальное решение, использующее этот выбор первым.

Если (2) не выполняется — жадность даст приближённое или неверное решение. Тогда нужно ДП или перебор.

## Жадность vs ДП

| | Жадность | ДП |
|---|---|---|
| Выбор | Делается раз и не пересматривается | Перебираются варианты, лучший запоминается |
| Сложность | Часто O(n log n) (нужна сортировка) | Полином по числу состояний |
| Доказательство корректности | Часто требует «обмена аргументов» | Индукция по построению таблицы |

## Классические задачи (где жадность работает)

### Activity selection (выбор занятий без пересечений)
Дано N интервалов `[s_i, f_i]`. Выбрать максимум непересекающихся.
- **Жадный критерий**: всегда брать интервал с самым ранним временем окончания.
- O(n log n) на сортировку.

### Размен монет (только для канонических систем)
Сумма S, монеты `[1, 5, 10, 50, 100]` (как у нас в кошельке).
- Брать по убыванию номинала, сколько влезает.
- **Внимание**: для произвольных номиналов жадность ломается. Например, монеты `[1, 3, 4]`, сумма 6: жадный даст `4 + 1 + 1 = 3 монеты`, а оптимум `3 + 3 = 2 монеты`. Тут только ДП.

### Алгоритм Хаффмана (префиксное кодирование)
Берём два символа с **наименьшими частотами**, объединяем в дерево, повторяем.
- Используем min-heap, O(n log n).

### Дейкстра
Жадный по природе: на каждом шаге фиксируем непосещённую вершину с минимальным расстоянием. Работает только с **неотрицательными** весами (см. [10-graphs](../10-graphs)).

### Минимальное остовное дерево (MST): Kruskal и Prim
- **Kruskal**: сортируем рёбра по весу, добавляем по очереди если не образуют цикл (DSU).
- **Prim**: растим дерево из одной вершины, на каждом шаге добавляем минимальное ребро на границе.

### Наибольшее число активностей одного работника
Сортировка по дедлайну, накопление штрафа — стандартный приём.

### Заправки на трассе
Цель: проехать N км, баки на K км, заправки в точках. Доехать с минимумом заправок.
- Едем максимально далеко с текущим баком, заправляемся в самой дальней достижимой.

## Когда жадность ломается (нужно ДП)

- Задача о рюкзаке 0/1: можно жадно по `value/weight`, но это неоптимально.
- Размен монет в произвольной системе.
- LCS, edit distance.

## Шаблон рассуждений «жадность + обмен аргументов»

Чтобы доказать, что жадный критерий правильный:
1. Берём произвольное оптимальное решение OPT.
2. Показываем: если в OPT первый выбор отличается от жадного, можно «обменять» его на жадный и получить решение не хуже OPT.
3. Дальше — индукция: остаточная задача — той же структуры, повторяем.
