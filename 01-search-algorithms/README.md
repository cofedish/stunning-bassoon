# 01. Алгоритмы обхода и поиска: BFS и DFS

Базовые способы пройти по структуре (граф, дерево, лабиринт). Разница только в том, какой контейнер использовать для «ещё не обработанных» вершин.

## Сравнительная таблица

| Свойство | BFS (поиск в ширину) | DFS (поиск в глубину) |
|---|---|---|
| Контейнер | Очередь (FIFO) | Стек / рекурсия (LIFO) |
| Идея | Сначала ближайшие, потом дальние | Уходим в глубину, потом откат |
| Кратчайший путь в **невзвешенном** графе | Да | Нет |
| Топологическая сортировка | Через Кана (in-degree) | Классический способ |
| Поиск циклов | Можно, но неудобно | Удобно (цвета вершин) |
| Память | O(V) — может хранить целый «уровень» | O(h) — глубина рекурсии |
| Время | O(V + E) | O(V + E) |

`V` — число вершин, `E` — число рёбер.

## BFS — пошагово

1. Положить стартовую вершину в очередь, отметить как посещённую.
2. Пока очередь не пуста:
   - Достать вершину из начала очереди.
   - Для каждого её непосещённого соседа: отметить и положить в конец очереди.
3. Готово, когда очередь опустела (или нашли цель).

Используется для: кратчайший путь в невзвешенном графе, «ближайшие N вершин», волновой алгоритм на сетке (лабиринт).

## DFS — пошагово

1. Стартуем с вершины `v`, отмечаем посещённой.
2. Для каждого непосещённого соседа — рекурсивно запускаем DFS.
3. Когда все соседи обработаны — возвращаемся.

Используется для: поиск компонент связности, обнаружение циклов, топологическая сортировка, мосты/точки сочленения, генерация лабиринтов.

## Типичные ловушки

- **Не отмечать посещённость** → бесконечный цикл на графе с циклами.
- **Отмечать в момент извлечения, а не помещения в BFS** → дубли в очереди и квадратичная сложность.
- **Глубокий DFS на Python** → `RecursionError`. Лимит по умолчанию 1000. Лечится либо `sys.setrecursionlimit`, либо итеративной версией со стеком.
- **DFS даёт «путь», но не кратчайший** — для длины пути в невзвешенном графе нужен BFS.

## Когда что брать

- Лабиринт, минимальное число шагов, «ближайший» — **BFS**.
- Все варианты пути, перебор, рекурсивная структура (дерево) — **DFS**.
- Веса рёбер ≠ 1 — ни то ни другое, нужен Дейкстра / 0-1 BFS / A*.
